# takealook97/homebrew-tap

Homebrew formulae for [`vat`](https://github.com/takealook97/vat) — a control
plane for multi-repo workspaces, and the brain that remembers why.

```bash
brew install takealook97/tap/vat
```

Or tap first, then install:

```bash
brew tap takealook97/tap
brew install vat
```

## Upgrading

```bash
brew update && brew upgrade vat
```

## Formulae

| Formula | Description |
| --- | --- |
| `vat` | Multi-repo workspace control plane with a knowledge layer whose claims expire |
